The UI labels stop tiles as `<类别>插画`, uses alt text like `寺庙类地点插画`, keeps real photos when a stop has one, and falls back to the gradient + icon tile if an illustration fails to load. Categories `夜游`, `逛街` and the generic `地点` keep the gradient + icon tile.
